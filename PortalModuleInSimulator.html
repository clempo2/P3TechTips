Portal Module in Simulator

This tech tip describes the steps to configure the simulator to use the Portal module.

ModuleID

First, set the ModuleID to Portal in .\Configuration\AppConfig.json:

          "ModuleID": "Portal",

ModuleVersion

The module driver version is the version of the module software.

The module version is the version of the module hardware. For example, this can indicate hardware changes when going from whitewood, to preproduction, and finally production. On the physical machine, the module version is saved on the USB stick in the back of the module.

In the simulator, the module version defaults to 0.0. For some module drivers, that does not matter since there is only one hardware version implemented. For Portal, the default selects the earliest prototype, which uses different switch and LED mappings. To configure the simulator to use the production version, add this line to AppConfig.json under the ModuleID line:

"ModuleVersion": "0.6.0.1",

Playfield Extender

The playfield extender is unavailable by default in the simulator. To enable the playfield extender, set the initial value of the RightRamp switch to inactive. To do this, add this line to the end of the DefaultSimSwitchStates section in AppConfig.json (also make sure to add a comma at the end of the previous line):

{"Switch":"RightRamp", "Active": false}

This will change the value of the L2Disabled GameAttribute to false, as shown in the service menu under “Settings/Mechs”:

To disable the playfield extender to test with Portal Standard, change the initial value of the RightRamp switch to active:

{"Switch":"RightRamp", "Active": true}
